> Generated by `scripts/generate_cli_docs.py` from the `oe` argument parser.

Backend commands talk to the selected backend (`--backend`, else `ENGINE_BACKEND`, else the one `oe backend use` chose). List commands print a table unless `--json` is given; other backend commands print readable lines unless `--json` is given. Exit status is 0 on success, 1 on a refusal or failed run, and 2 on a usage mistake. See [Graphs](graphs.md), [Loops](loops.md) and the [graph and loop specifications](cli-specs.md).

## `oe go`

Make a change with the default graph and follow it live.

Follows live on a TTY. With --json, prints JSON and sends the mode banner to stderr.

```text
oe go [-h] [--json] [--backend NAME] [--project NAME] [--trust | --no-trust] [--repo REPO]
      [--local] [--review PR_OR_BRANCH] [--spec] [--input KEY=VALUE] [--wait]
      [--timeout SECONDS]
      [VERB/TARGET/INSTRUCTION ...]
```

| Argument | Meaning |
| --- | --- |
| `--json` | JSON instead of readable output |
| `--backend NAME` | the backend to use (default: the selected one) |
| `--project NAME` | the project names resolve in (default: the backend's) |
| `VERB/TARGET/INSTRUCTION` | instruction, or a verb and change target |
| `--trust, --no-trust` | remember whether agents may run without approval here |
| `--repo REPO` | repository (default: the current checkout) |
| `--local` | force disconnected mode; keep work local |
| `--review PR_OR_BRANCH` | review an existing change with the review verb graph |
| `--spec` | write a specification before implementing |
| `--input, -i KEY=VALUE` |  |
| `--wait` | wait non-interactively for completion |
| `--timeout SECONDS` |  |

```text
examples:
  oe go "add a widget"
  oe go fix https://github.com/OpenEngine/OpenEngine/pull/855
```

### `oe graph run`

Run a graph with an instruction.

Follows live when stdin and stdout are TTYs, unless --wait, --json or --no-watch is given.

```text
oe graph run [-h] [--json] [--backend NAME] [--project NAME] [--input NAME=VALUE]
             [--branch BRANCH] [--agent AGENT] [--local] [--trust | --no-trust] [--repo REPO]
             [--no-watch] [--wait] [--timeout SECONDS] [--idempotency-key IDEMPOTENCY_KEY]
             graph [instruction]
```

| Argument | Meaning |
| --- | --- |
| `--json` | JSON instead of readable output |
| `--backend NAME` | the backend to use (default: the selected one) |
| `--project NAME` | the project names resolve in (default: the backend's) |
| `graph` | a graph, or a built-in one: implementation-review-rerank, review, fix |
| `instruction` | what to do (default: run the graph) |
| `--input, -i NAME=VALUE` |  |
| `--branch BRANCH` | the branch to check out (sets the branch input) |
| `--agent AGENT` | the agent to run (sets the agent input) |
| `--local` | keep commits and findings local; do not publish |
| `--trust, --no-trust` | remember whether agents may run without approval here |
| `--repo REPO` | repository to check out |
| `--no-watch` | return immediately without the live view |
| `--wait` | wait for the run to finish |
| `--timeout SECONDS` | give up waiting after this long |
| `--idempotency-key IDEMPOTENCY_KEY` | reuse to make a resubmission safe |

## `oe loop`

Recurring runs of a graph, within limits.

```text
oe loop [-h] {spec,add,get,pause,resume,stop,list} ...
```

### `oe loop spec`

Print the current loop specification.

Prints the [specification](cli-specs.md) as Markdown, without contacting a backend.

```text
oe loop spec [-h]
```

### `oe loop add`

Run a graph on a cadence.

```text
oe loop add [-h] [--json] [--backend NAME] [--project NAME] [--name NAME]
            [--instruction INSTRUCTION] [--every EVERY] [--max-prs MAX_PRS] [--max-spend USD]
            [--trust | --no-trust] [--repo REPO] [--input NAME=VALUE] [--no-run-now]
            graph
```

| Argument | Meaning |
| --- | --- |
| `--json` | JSON instead of readable output |
| `--backend NAME` | the backend to use (default: the selected one) |
| `--project NAME` | the project names resolve in (default: the backend's) |
| `graph` |  |
| `--name NAME` | loop name (default: the graph's) |
| `--instruction INSTRUCTION` | override the graph's loop.instruction |
| `--every EVERY` | cadence such as 30m, 6h, 1d (default: the graph's loop.every) |
| `--max-prs MAX_PRS` | pause after this many new pull requests |
| `--max-spend USD` | pause, and stop the active run, at this spend |
| `--trust, --no-trust` | remember whether agents may run without approval here |
| `--repo REPO` |  |
| `--input, -i NAME=VALUE` |  |
| `--no-run-now` | first run after one interval, not now |
