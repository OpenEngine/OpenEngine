> Generated by `scripts/generate_cli_docs.py` from the `engine` argument parser.

Backend commands talk to the selected backend (`--backend`, else `ENGINE_BACKEND`, else the one `engine backend use` chose) and print JSON unless `--pretty` is given. Exit status is 0 on success, 1 on a refusal or failed run, and 2 on a usage mistake. See [Graphs](graphs.md), [Loops](loops.md) and the [graph and loop specifications](cli-specs.md).

## `engine connect`

Connect shared source control or Slack.

```text
engine connect [-h] [--server URL] [--backend NAME] [--origin ORIGIN] [--open]
               {gh,github,gitlab,slack}
```

| Argument | Meaning |
| --- | --- |
| `provider` | one of `gh`, `github`, `gitlab`, `slack` |
| `--server URL` | override the selected backend's URL |
| `--backend NAME` | the backend to connect (default: the selected one) |
| `--origin ORIGIN` | the GitLab instance to connect |
| `--open` | open the authorization page in a browser |

| Argument | Meaning |
| --- | --- |
| `--backend NAME` | the backend to use (default: the selected one) |

### `engine graph run`

Run a graph with an instruction.

```text
engine graph run [-h] [--backend NAME] [--pretty] [--project NAME] [--input NAME=VALUE]
                 [--branch BRANCH] [--agent AGENT] [--repo REPO] [--wait] [--timeout SECONDS]
                 [--idempotency-key IDEMPOTENCY_KEY]
                 graph [instruction]
```

| Argument | Meaning |
| --- | --- |
| `--backend NAME` | the backend to use (default: the selected one) |
| `--pretty` | human-readable output instead of JSON |
| `--project NAME` | the project names resolve in (default: the backend's) |
| `graph` | a graph, or a built-in one: review, adversarial-review, implement-review, spec-implement-review |
| `instruction` | what to do (default: run the graph) |
| `--input, -i NAME=VALUE` |  |
| `--branch BRANCH` | the branch to check out (sets the branch input) |
| `--agent AGENT` | the agent to run (sets the agent input) |
| `--repo REPO` | repository to check out |
| `--wait` | wait for the run to finish |
| `--timeout SECONDS` | give up waiting after this long |
| `--idempotency-key IDEMPOTENCY_KEY` | reuse to make a resubmission safe |

## `engine loop`

Recurring runs of a graph, within limits.

```text
engine loop [-h] {spec,add,get,pause,resume} ...
```

### `engine loop spec`

Print the current loop specification.

Prints the [specification](cli-specs.md) as Markdown, without contacting a backend.

```text
engine loop spec [-h]
```

### `engine loop add`

Run a graph on a cadence.

```text
engine loop add [-h] [--backend NAME] [--pretty] [--project NAME] [--name NAME]
                [--instruction INSTRUCTION] [--every EVERY] [--max-prs MAX_PRS]
                [--max-spend USD] [--repo REPO] [--input NAME=VALUE] [--no-run-now]
                graph
```

| Argument | Meaning |
| --- | --- |
| `--backend NAME` | the backend to use (default: the selected one) |
| `--pretty` | human-readable output instead of JSON |
| `--project NAME` | the project names resolve in (default: the backend's) |
| `graph` |  |
| `--name NAME` | loop name (default: the graph's) |
| `--instruction INSTRUCTION` | override the graph's loop.instruction |
| `--every EVERY` | cadence such as 30m, 6h, 1d (default: the graph's loop.every) |
| `--max-prs MAX_PRS` | pause after this many new pull requests |
| `--max-spend USD` | pause, and stop the active run, at this spend |
| `--repo REPO` |  |
| `--input, -i NAME=VALUE` |  |
| `--no-run-now` | first run after one interval, not now |

### `engine agent claude`

Drive an implementation node with Claude Code in this terminal.

Start a run whose implementation node is Claude Code in this terminal, working in a fresh workspace with the tools [sessions] grants in engine.toml. Arguments after -- go to claude.

```text
engine agent claude [-h] [--repo REPO] [--base REF] [--backend NAME] ...
```

| Argument | Meaning |
| --- | --- |
| `--repo REPO` | a path inside the repository (default: the current directory) |
| `--base REF` | what the workspace starts from (default: the backend's) |
| `--backend NAME` | the backend to use; it must run on this machine |
| `claude_args` | passed to claude after -- |
