What it does

  • Run on a schedule

    Put a graph on a cadence: nightly dependency upkeep, flaky-test fixes, issue triage. It runs while nobody is at the keyboard.

  • Continuous security review

    A daily graph maps your public API surface, a second model tries to disprove each finding, and confirmed ones become scoped issues with a reproduction.

  • Steer it from Slack or the PR

    Reply in the thread or comment on the pull request and the correction reaches the agent that is working. Ask for more afterwards and the same run resumes.

  • Cap spend and pull requests

    Every loop has a budget and a limit on the pull requests it opens, so agents never get ahead of your reviewers.
