## Non-blocking coverage finding

**[P3] Exercise summary overflow in a real browser.** The long-line test in
`apps/web/src/markdown.test.tsx` and the long-summary test in
`apps/web/src/runs.test.tsx` assert text content and DOM ancestry only. They do
not load the stylesheet, and jsdom does not calculate layout. Both tests would
pass if Markdown wrapping and code-block scrolling were removed. The image
browser test does not cover containment either.

Add a browser test at a narrow viewport with a long unbroken string and a wide
fenced code block. Assert that the document does not become wider than the
viewport and that the code block scrolls within the card. This protects the
explicit containment acceptance criterion against CSS regressions.
